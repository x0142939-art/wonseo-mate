취업 준비에 필요한 작은 도구들을 모아뒀어요. 모든 처리는 브라우저 안에서만 이뤄지고, 어떤 데이터도 서버로 전송되지 않아요.

📄 지원서류 준비하기

학점 정리 → 증명사진 → 자소서, 순서대로 따라오시면 지원서류가 완성돼요.

🎓

① 학점 계산기

대학 학점(GPA)과 고등학교 내신 등급을 계산하고, 목표 점수를 위해 필요한 평균도 알려드려요.
🪪

② 증명사진 보정기

사진관에서 받은 사진을 여권·증명사진·이력서용 규격에 맞게 자르고 밝기·대비를 다듬어요.
📝

③ 자소서 작성 도구

국내·해외 표준 양식으로 자소서를 쓰고, 글자수 확인과 무료 맞춤법 검사, 회사 정보 검색까지 한 번에.

🔍 채용정보 찾기

서류가 준비됐다면, 지원할 곳을 찾아보세요.
