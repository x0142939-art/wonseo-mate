# 원서메이트

취업 준비생을 위한 브라우저 전용 유틸리티 모음입니다. 모든 처리는 클라이언트(브라우저) 안에서만 이뤄지며, 어떤 데이터도 서버로 전송되지 않습니다.

## 폴더 구조

```
web-tools/
├── index.html              # 랜딩 페이지
├── gpa-calculator/          # 대학 학점(GPA) + 고교 내신 등급 계산기
└── id-photo-editor/         # 증명사진 규격 자르기·밝기/대비 보정 도구
```

## 로컬 실행

별도 빌드나 서버 없이, 각 폴더의 `index.html`을 브라우저로 열면 바로 동작합니다.
